# 점심 메뉴 투표 사이트 "오늘 뭐 먹지?" - 설계 문서

## 개요
팀/부서 내부에서 점심 메뉴를 정할 때 사용하는 투표 사이트.
주변 음식점을 자동으로 불러오고, 사용자가 메뉴를 추가하고, 투표 후 최종 메뉴를 선정한다.
동률 시 무작위 추첨으로 결정한다.

## 핵심 플로우
1. 방장이 방 생성
2. 브라우저 위치 기반으로 반경 1km 주변 음식점 자동 로드 (네이버 Maps API)
3. 팀원들이 URL 공유받아 입장
4. 누구나 메뉴 추가 가능
5. 각자 마음에 드는 메뉴에 다중 투표
6. 방장이 투표 마감
7. 최다 득표 메뉴 선정, 동률이면 무작위 추첨

## 기술 스택
- **프론트엔드**: React 18 + Vite
- **실시간 DB**: Firebase Realtime Database
- **지도/장소 검색**: Naver Cloud Platform Maps API (Place Search)
- **배포**: Vercel 또는 Netlify (무료 티어)

## 주요 화면

### 1. 메인/방 생성 화면
- 닉네임 입력
- "방 만들기" 버튼 → 위치 권한 요청 후 방 생성
- 기존 방 코드 입력하여 참가

### 2. 방 로비 (투표 화면)
- 상단: 방 코드 표시 + 공유 버튼
- 중앙: 메뉴 리스트 (네이버 API로 불러온 음식점 + 사용자 추가 메뉴)
- 각 메뉴에 투표 버튼 + 현재 투표 수 실시간 표시
- 하단: 메뉴 직접 추가 입력 + 방장용 "투표 마감" 버튼

### 3. 결과 화면
- 투표 결과 바 차트
- 동률 시 룰렛/추첨 애니메이션
- 최종 선정 메뉴 강조 표시

## 데이터 구조 (Firebase Realtime DB)

```
rooms/
  {roomId}/
    createdAt: timestamp
    createdBy: "닉네임"
    status: "voting" | "closed"
    location: { lat, lng }
    menus/
      {menuId}/
        name: "김치찌개"
        source: "naver" | "custom"
        addedBy: "닉네임"
    votes/
      {oderId}/
        oderId: "닉네임"
        menuIds: ["menu1", "menu3"]
    result: {menuId} | null
```

## 핵심 기능 상세

### 주변 음식점 검색
- 방 생성 시 브라우저 Geolocation API로 현재 위치 획득
- 네이버 Place Search API로 반경 1km(1000m) 음식점 검색
- 결과를 메뉴 리스트에 자동 추가

### 메뉴 추가
- 누구나 텍스트로 메뉴 추가 가능
- source: "custom"으로 구분

### 투표
- 1인 다중 투표 (마음에 드는 메뉴 여러 개 선택 가능)
- 실시간으로 투표 수 반영 (Firebase 실시간 구독)

### 마감 & 추첨
- 방장이 "투표 마감" 클릭
- 최다 득표 1개 → 바로 선정
- 동률 → 해당 메뉴들로 무작위 추첨 (애니메이션 포함)

## 사용 규모
- 팀/부서 내부용 (5~20명)
- 로그인 불필요 (닉네임만 입력)
