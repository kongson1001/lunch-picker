# Room UI Redesign — Map-Centric Layout + 회식 날짜투표

## Goal

방 페이지를 카카오맵 스타일의 지도 중심 레이아웃으로 전환. 지도가 항상 전체 화면을 차지하고, 왼쪽 패널(데스크탑) 또는 하단 드래그 시트(모바일)로 기능을 제공. 회식방에 날짜·시간 투표 패널 추가.

## Architecture

### 반응형 분기점
- **≥ 768px (데스크탑)**: 2-컬럼 레이아웃 — 왼쪽 고정 패널(340px) + 오른쪽 지도(나머지 전체)
- **< 768px (모바일)**: 지도 전체화면 + 하단 드래그 시트

### 레이아웃 구조 (데스크탑)
```
┌─────────────────────────────────────┐
│ 헤더: 방이름 | 방코드 | 링크복사 | 나가기 │  ← 슬림 헤더 (44px)
├──────────────┬──────────────────────┤
│  왼쪽 패널   │                      │
│  (340px)     │    네이버 지도        │
│              │    (전체 높이)        │
│  패널 내용   │                      │
│  (아이콘으로 │   [🔍][🗳️][💬][🙋][🗓️] ← 우측 아이콘 세로 배열
│   전환)      │                      │
│              │              [📍]    │
└──────────────┴──────────────────────┘
```

### 레이아웃 구조 (모바일)
```
┌─────────────────────────┐
│ 헤더 (슬림)              │
├─────────────────────────┤
│                         │
│      네이버 지도          │  ← 전체화면
│                 [🔍]    │
│                 [🗳️]    │  ← 우측 아이콘 세로 배열
│                 [💬]    │
│                 [🙋]    │
│                         │
├─────────────────────────┤  ← 드래그 핸들
│  패널 내용               │  ← 하단 시트 (드래그 가능)
└─────────────────────────┘
```

## 패널 시스템

아이콘 클릭 시 왼쪽 패널(데스크탑) 또는 하단 시트(모바일) 내용이 교체됨.

| 아이콘 | 패널 | 내용 | 조건 |
|--------|------|------|------|
| 🔍 | 검색 | RestaurantSearch + 즐겨찾기 탭 | 항상. **기본값** |
| 🗳️ | 투표 | MenuList + AddMenu + 투표마감 버튼 | 항상 |
| 💬 | 채팅 | Chat 컴포넌트 | 항상 |
| 🙋 | 참여 | 참여여부 선택 + 참여자 현황 | 항상 |
| 🗓️ | 날짜투표 | ScheduleVote + AddSchedule | 회식방(`roomType === 'hoesik'`)만 표시 |

선택된 아이콘: 주황색(#e85d26) 배경 + white 아이콘.
비선택 아이콘: white 배경 + 그림자.

## 모바일 드래그 시트 동작

- **초기 높이**: 화면 높이의 50%
- **최대 높이**: 화면 높이의 85% (지도 일부 보임)
- **최소 높이**: 120px (핸들만 보임, 지도 최대화)
- **아이콘 클릭 시**: 패널 교체 + 시트 50%로 리셋
- 드래그 핸들: 시트 상단 중앙의 회색 바 (36×4px)
- 드래그는 touchstart/touchmove/touchend 이벤트로 구현 (별도 라이브러리 없이)

## 헤더 변경

기존의 방 제목, 방코드, 버튼들을 슬림하게 단일 헤더바로 통합:
- 왼쪽: 방 이름 (클릭 시 수정 가능, 방장만)
- 오른쪽: 방코드 | 링크복사 | 나가기
- 높이: 44px (기존 헤더보다 작게)

## 날짜·시간 투표 (회식방 신규 기능)

기존 `ScheduleVote`, `AddSchedule` 컴포넌트를 🗓️ 패널로 연결. 별도 DB 변경 없음.

## 파일 변경 범위

**수정:**
- `app/room/[roomId]/page.js` — 전체 레이아웃 재구성, 패널 상태 관리 추가
- `app/globals.css` — 기존 room-section/room-body 스타일 제거, 새 레이아웃 CSS 추가

**신규:**
- `app/components/BottomSheet.js` — 모바일 드래그 시트 컴포넌트
- `app/components/RoomPanel.js` — 패널 컨테이너 (아이콘 + 패널 내용 관리)

**유지 (내부 변경 없음):**
- `app/components/MenuList.js`
- `app/components/RestaurantSearch.js`
- `app/components/Chat.js`
- `app/components/ScheduleVote.js`
- `app/components/AddSchedule.js`
- `app/components/NaverMap.js`

## 구현 제약

- 외부 드래그 라이브러리 사용 금지 (touch 이벤트 직접 구현)
- 기존 컴포넌트 내부 수정 없이 레이아웃만 재구성
- `globals.css` 기존 스타일 파괴 없이 새 클래스 추가
